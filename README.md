# 智能核桃分拣系统

基于树莓派 + STM32 的双平台 AI 视觉分拣系统。

## 功能概述

- 传送带三工位（等候区/待检区/监测区）协同工作，红外传感器 + 闸门控制核桃逐个进入检测区域
- 树莓派端运行 YOLOv8s 进行核桃品质检测（完好/破损/未熟），模型剪枝 + INT8 量化压缩至 7.8MB
- 连续采集 5 帧进行投票，有效过滤单帧误检
- 九点标定 + 仿射变换实现像素坐标到机械臂基座坐标的实时映射，定位精度 ±3mm
- 树莓派与 STM32 通过 UART 串口通信，自定义指令协议完成检测结果到执行指令的透传

## 目录结构

- `RaspberryPi/` - 树莓派视觉识别与决策模块
- `STM32/` - STM32 底层控制模块（红外传感器、闸门、传送带、机械臂联动）

## 运行说明
复制树莓派部分代码到进树莓派对应位置，并将STM32部分代码编译烧录进STM32，正确接线
在树莓派上执行：
```bash
python3 main.py

## 技术栈

- **树莓派端**：Python、OpenCV、YOLOv8s、ONNX Runtime、PySerial
- **STM32端**：C语言、Keil5、UART通信
